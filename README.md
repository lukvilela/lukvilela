## 🎬 Sobre mim

Sou desenvolvedor full-stack apaixonado por **construir produtos de ponta a ponta** — e por cinema, o que me deixa meio obcecado por experiência, ritmo e acabamento. No dia a dia eu desenho a interface, escrevo a API, modelo o banco, conecto integrações (pagamentos, IA, APIs externas) e coloco em produção.

- 🤖 **Integração de IA/LLM** em produtos reais (análise de currículo/entrevista, agentes, automações)
- 🔌 **Integrações de verdade**: Stripe, LinkedIn API, automações N8N, WhatsApp, GitHub
- 🚀 **Do código ao deploy**: Docker, Cloud Run, Vercel, Netlify, Firebase
- 🧩 Gosto de **resolver o problema inteiro**, não só uma camada
